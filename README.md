# 초고속 문서리더 (PDF / HWP / HWPX)

휴대폰에서 PDF와 한글 문서를 빠르게 열어 보는 안드로이드 앱입니다. (Android 8.0 이상)

## 기능

- **PDF**: 안드로이드 내장 PdfRenderer로 페이지를 필요한 만큼만 그려서 큰 파일도 바로 열립니다.
  핀치·더블탭 확대, 확대 시 고해상도 재렌더링, 야간(반전) 보기, 페이지 이동.
- **HWP (한글 5.0 이상) / HWPX**: 외부 라이브러리 없이 직접 구현한 파서로 문서 모양까지 읽습니다.
  - **원본 보기(기본)**: 한글에서 보던 쪽 모양 그대로 — 줄바꿈 위치, 글꼴 크기·굵기·색, 정렬, 들여쓰기,
    표(병합 셀·테두리·배경), 그림, 글상자·도형, 쪽 테두리/배경, 머리말·꼬리말, 쪽 번호, 각주·미주, 수식.
    두 손가락으로 확대할 수 있고 화면 폭에 맞춰 쪽을 보여줍니다.
  - **읽기 모드**: 글자를 화면 폭에 맞춰 다시 흘려 보여줍니다. 문단·줄바꿈·글자 모양과 표는 그대로 유지하고,
    글자 크기를 70~200%로 바꿀 수 있습니다. 하단 막대의 '원본 / 읽기' 버튼으로 같은 위치에서 바로 전환됩니다.
  - **배포용 문서(읽기 전용)** 도 열립니다. 문서 모양을 그리지 못하는 문서는 텍스트만이라도 보여줍니다.
- 본문 검색(결과 이동·강조), 글자 크기 조절, 문서별 읽은 위치 기억.
- 최근 문서, 공유 / 다른 앱으로 열기, 전체 텍스트 복사, 다크 모드.
- 파일 관리자·카카오톡·메일 등에서 "열기"와 "공유"로 바로 열 수 있습니다(.hwpx 포함).
  파일 이름이나 MIME 형식이 틀려도 파일 내용을 보고 형식을 판별합니다.

지원하지 않는 것: 암호가 걸린 문서, HWP 3.0(한글 97 이전) 형식.
한컴 전용 글꼴이 휴대폰에 없으므로 비슷한 글꼴로 그리고 글자 폭은 원본 줄에 맞게 자동 조정합니다.
WMF/EMF 같은 일부 그림 형식은 자리 표시로 나옵니다. 열 수 없는 문서는 앱이 종료되지 않고 이유를 안내합니다.

## 빌드

GitHub에 push하면 Actions가 테스트 후 APK를 만듭니다.

**설치용 APK는 GitHub의 Releases에서 받으세요.** `v`로 시작하는 태그(예: `v1.2`)를 올리면
Actions가 그 버전의 Release를 만들고 `FastDocReader-v1.2.apk`를 붙입니다.

```bash
git tag v1.2
git push origin v1.2
```

평소 push한 빌드는 Actions 실행 결과의 **Artifacts → FastDocReader-apk** 에서 30일 동안 받을 수 있습니다.

로컬 빌드:

```bash
./gradlew testDebugUnitTest assembleRelease
```

## 구조

```
app/src/main/java/com/fastreader/app/
├── MainActivity.kt          홈: 최근 문서 카드 + 하단 '파일 열기'
├── ViewerActivity.kt        문서 화면: 하단 도구 막대(검색·글자·페이지·공유)
├── core/                    안드로이드 의존성이 없는 파서·렌더러 (단위 테스트 대상)
│   ├── CompoundFile.kt      OLE2 컨테이너 리더
│   ├── HwpParser.kt         HWP 5.x 본문 텍스트 (문서 모양을 못 그릴 때 대체용)
│   ├── HwpxParser.kt        HWPX(OWPML) 본문 텍스트 (대체용)
│   ├── DocumentType.kt      내용 기반 형식 판별
│   ├── doc/                 문서 모양 공통 모델 (글자/문단 모양, 표, 그림, 쪽 설정)
│   ├── hwp/, hwpx/          HWP·HWPX → 공통 모델 파서
│   └── render/              공통 모델 → HTML (원본 보기 / 읽기 모드) + 화면용 스크립트
├── viewer/                  PDF 렌더링, 한글 문서 WebView(RichDocView), 그림 캐시, ViewModel
└── data/                    최근 문서 · 설정 저장
```
